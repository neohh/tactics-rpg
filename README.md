# ⚔️ Пошаговый бой — Turn-Based Tactics RPG

Пошаговая тактическая RPG с 3D-картами, отрядом героев и пошаговым боем на сетке.

## 🎮 Об игре

Вы управляете отрядом до 6 героев, перемещаетесь по глобальной карте, исследуете локации в свободном режиме и сражаетесь с врагами в пошаговых тактических боях.

### Основные механики

**🗺️ Глобальная карта**
- Путешествуйте между локациями по связанным маршрутам
- Потратьте еду на перемещение или терпите усталость
- Случайные встречи с врагами (35% шанс при перемещении)
- Взаимодействие с NPC: торговцы, старосты, таверны

**🚶 Свободное исследование**
- WASD перемещение отрядом по 3D-локации
- Свободная камера: вращение (ПКМ), панорамирование (СКМ), зум (колесо)
- Подбирайте лут с земли (клавиша E)
- Говорите с NPC, покупайте товары в магазинах
- Отряд автоматически вступает в бой при соприкосновении с врагом

**⚔️ Пошаговый бой**
- Бои на клетчатой сетке с 3D-персонажами
- Динамический бюджет активаций на раунд (рассчитывается по живым бойцам через `StatsTools.activations_for`)
- Юниты «прилипают» к клеткам при входе в бой
- Зональный урон: атака спереди / сбоку / сзади влияет на шанс попадания
- Реальные производные характеристики (`StatsTools.derived`): HP, атака, дальность, шаги, шансы попадания
- Кастомные навыки для каждого класса (толчок, огненные стрелы, лечение, огонь 3×3)
- QTE-система: нажимайте SPACE вовремя для бонуса к атаке или блока

**🛡️ Классы героев**

| Класс | Особенность |
|-------|-------------|
| ⚔️ Мечник | Толчок врагов, высокий шанс попадания спереди |
| 🏹 Лучник | Дальний бой (радиус 8), огненные стрелы |
| 🗡️ Убийца | Высокая скорость (5 клеток), проскользнуть сквозь юниты, удары в спину |
| 🔱 Алебардист | Радиус 2, автоматический удар ближайших врагов |
| 🔮 Маг | Лечение союзников, огненная аура 3×3 |

**📈 Прогрессия**
- Получайте опыт за убийство врагов
- Уровни дают перк-поинты
- Перки: стойкость (+HP), точность (+к попаданию), классовые навыки
- Экипировка: оружие, броня, аксессуары

**🏕️ Лагерь и быт**
- Отдых в лагере (клавиша R) восстанавливает силы
- День/ночь цикл: 24 часа, еда тратится на перемещение
- Автосохранение при входе в локацию

### Квесты
- Квесты с этапами: добраться до точки, поговорить с NPC, очистить локацию
- Журнал заданий (клавиша J)
- Автоматическое обновление при выполнении условий

## 🛠️ Технологии

- **Движок:** Godot 4.7 (Forward Plus)
- **Физика:** Jolt Physics
- **3D:** Террейн на чанках, billboard-спрайты, декали
- **Данные:** JSON-файлы для всех игровых данных

| Вращение камеры | ПКМ + движение мыши |
| Панорамирование камеры | СКМ + движение мыши |
| Зум камеры | Колесо мыши |

### Режим Конструктора (Content Constructor)
- Вызывается горячей клавишей **C** из любой сцены или кнопкой **«КОНСТРУКТОР»** в главном меню (`menu.tscn`).
- Открывается в независимом управляемом окне (`Window`) поверх игры без крашей и сбоев.
- Поддерживает 10 категорий данных (`chars`, `items`, `classes`, `objects`, `mats`, `locs`, `catalog`, `map`, `dialogs`, `quests`), группировку по папкам (`groups.json`), нодовый редактор диалогов, 2D-сетку расстановки (`loc_editor.gd`) и 3D-мастерскую террейна (`work3d.gd`).

## 📁 Структура проекта

```
data/                     — JSON-база данных игры (локации, классы, предметы, квесты, диалоги, материалы)
scripts/                  — GDScript игровая логика
│   ├── game.gd           — Синглтон Game: состояние, инвентарь, отряд, слоты сохранений
│   ├── con_hotkey.gd     — Синглтон ConHotkey: хоткей [C] и запуск Конструктора
│   ├── data_loader.gd    — Централизованная загрузка и безопасное сохранение JSON
│   ├── stats_tools.gd    — Расчет итоговых параметров, производных статов и бюджета активаций
│   ├── party_tools.gd    — Управление отрядом (найм, уровни, расчет HP)
│   ├── world3d.gd        — Тактическая боевая сцена (сетка, статы, ИИ, навыки, огонь)
│   ├── overworld3d.gd    — 3D глобальная карта мира, маршруты, редактор мира
│   ├── explore3d.gd      — Свободное исследование 3D-локации отрядом
│   ├── constructor.gd    — Универсальный внутриигровой редактор контента
│   ├── loc_editor.gd     — 2D-редактор локаций и расстановка на сетке
│   ├── work3d.gd         — 3D-мастерская ландшафта, чанков, декораций и света
│   ├── dialog*.gd        — Движок и нодовый редактор диалоговых графов
│   ├── game_hub.gd       — Меню героя, экипировка, перки, характеристики
│   └── archive_unused/   — Архив ранних прототипных модулей боя
art/                      — 2D/3D ассеты (текстуры, портреты, модели)
addons/                   — Плагины движка Godot
```

## 🚀 Запуск

1. Клонируйте репозиторий: `git clone https://github.com/neohh/tactics-rpg.git`
2. Откройте проект в **Godot 4.3+** (проект настроен под Godot 4.7 Forward Plus)
3. Запустите проект (F5) — стартовая сцена `res://menu.tscn`
