# ⚔️ Пошаговый бой — Turn-Based Tactics RPG

Пошаговая тактическая RPG с 3D-картами, отрядом героев и пошаговым боем на сетке.

## 🎮 Об игре

Вы управляете отрядом до 6 героев, перемещаетесь по глобальной карте, исследуете локации в свободном режиме и сражаетесь с врагами в пошаговых тактических боях.

### Основные механики

**🗺️ Глобальная карта**
- Путешествуйте между локациями по связанным маршрутам
- Потратьте еду на перемещение или терпите усталость
- Случайные встречи с врагами (35% шанс при перемещении)
- Взаимодействие с NPC: торговцы, старосты, таверны

**🚶 Свободное исследование**
- WASD перемещение отрядом по 3D-локации
- Свободная камера: вращение (ПКМ), панорамирование (СКМ), зум (колесо)
- Подбирайте лут с земли (клавиша E)
- Говорите с NPC, покупайте товары в магазинах
- Отряд автоматически вступает в бой при соприкосновении с врагом

**⚔️ Пошаговый бой**
- Бои на клетчатой сетке с 3D-персонажами
- 2 активации за ход — используйте разные фигуры или одну дважды
- Юниты «прилипают» к клеткам при входе в бой
- Зональный урон: атака спереди / сбоку / сзади влияет на шанс попадания
- Кастомные навыки для каждого класса
- QTE-система: нажимайте SPACE вовремя для бонуса к атаке или блока

**🛡️ Классы героев**

| Класс | Особенность |
|-------|-------------|
| ⚔️ Мечник | Толчок врагов, высокий шанс попадания спереди |
| 🏹 Лучник | Дальний бой (радиус 8), огненные стрелы |
| 🗡️ Убийца | Высокая скорость (5 клеток), проскользнуть сквозь юниты, удары в спину |
| 🔱 Алебардист | Радиус 2, автоматический удар ближайших врагов |
| 🔮 Маг | Лечение союзников, огненная аура 3×3 |

**📈 Прогрессия**
- Получайте опыт за убийство врагов
- Уровни дают перк-поинты
- Перки: стойкость (+HP), точность (+к попаданию), классовые навыки
- Экипировка: оружие, броня, аксессуары

**🏕️ Лагерь и быт**
- Отдых в лагере (клавиша R) восстанавливает силы
- День/ночь цикл: 24 часа, еда тратится на перемещение
- Автосохранение при входе в локацию

### Квесты
- Квесты с этапами: добраться до точки, поговорить с NPC, очистить локацию
- Журнал заданий (клавиша J)
- Автоматическое обновление при выполнении условий

## 🛠️ Технологии

- **Движок:** Godot 4.7 (Forward Plus)
- **Физика:** Jolt Physics
- **3D:** Террейн на чанках, billboard-спрайты, декали
- **Данные:** JSON-файлы для всех игровых данных

## 🎮 Управление

### Глобальная карта
| Действие | Клавиша |
|----------|---------|
| Войти в локацию | ЛКМ по локации |
| Вращение камеры | ПКМ +移动 |
| Панорама | СКМ +移动 |
| Зум | Колесо мыши |

### Свободное исследование
| Действие | Клавиша |
|----------|---------|
| Движение отряда | WASD |
| Вращение камеры | ПКМ +移动 |
| Подобрать лут | E |
| Лагерь | R |
| Отряд | P |
| Карта | M |

### Бой
| Действие | Клавиша |
|----------|---------|
| Выбрать юнита | ЛКМ |
| Повернуть | Q / E |
| Завершить ход | Кнопка |
| Огонь (маг) | Кнопка «Огонь 3×3» |
| Управление камерой | ПКМ / СКМ / Колесо |

## 📁 Структура проекта

```
data/            — JSON-данные (локации, классы, предметы, квесты)
scripts/         — GDScript логика
art/             — Спрайты, модели, текстуры
addons/          — Плагины Godot
```

## 🚀 Запуск

1. Клонируйте репозиторий
2. Откройте `project.godot` в Godot 4.7
3. Нажмите Play (F5)
